# Security Policy

Please do not commit credentials, private keys, tokens, personal data, or unreviewed external payloads. Use environment variables or a secret manager for credentials.

Report suspected security issues privately to the repository owner rather than opening a public issue. Rotate any credential that may have been exposed before discussing the incident.

This policy is a repository hygiene baseline. It does not certify that the historical source tree contains no secrets; run the S+ audit and review its redacted findings.
